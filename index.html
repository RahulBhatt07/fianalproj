What is Reinforcement Learning?

🎮

Definition

Reinforcement Learning is a type of machine learning where an agent learns to make decisions by taking actions in an environment to maximize cumulative reward.

🧠

How It Works

The agent interacts with its environment, takes actions, observes results, receives rewards/penalties, and adjusts its strategy to maximize long-term rewards.

🎯

Applications in Games

RL excels in games because they provide clear rules, states, actions, and rewards. It's been used to master chess, Go, Dota 2, StarCraft II, and many other games.

Q-Learning: The Foundation of Game AI

Q-Learning is one of the most popular reinforcement learning algorithms. It creates a "Q-table" that maps state-action pairs to expected rewards.

Q(s,a) ← Q(s,a) + α[r + γ·maxa'Q(s',a') - Q(s,a)]

Where:

  • Q(s,a): Value of taking action a in state s
  • α: Learning rate (how quickly new information overrides old)
  • r: Reward received
  • γ: Discount factor (importance of future rewards)
  • maxa'Q(s',a'): Maximum expected future reward

In games like Flappy Bird, Q-Learning helps the agent learn when to jump based on its current position, pipe distances, and other factors.
